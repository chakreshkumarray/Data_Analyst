-- 1. MYSQL --
--- 1. What is DataBase ---

🔹 1. BASIC DATABASE QUESTIONS
❓ What is a Database?
A database is an organized collection of data that can be easily accessed and managed.

❓ What is DBMS?
DBMS (Database Management System) is software used to:
Store data
Retrieve data
Manage data
👉 Examples: MySQL, PostgreSQL, Oracle

❓ What is RDBMS?
Relational DBMS stores data in tables (rows & columns) and uses relationships.

❓ Difference: DBMS vs RDBMS
DBMS	RDBMS
No relations	Has relationships
Small systems	Large systems

🔥 🔹 TYPES OF RELATIONSHIPS
✅ 1. One-to-One (1:1)

👉 One record in Table A = One record in Table B

Example:
One person → One passport
Person	Passport
1	P101

✅ 2. One-to-Many (1:M) ⭐ MOST IMPORTANT

👉 One record in Table A = Many records in Table B

Example:
One customer → Many orders
-- customers table
id (PK)

-- orders table
customer_id (FK)

👉 Used in most real-world systems

✅ 3. Many-to-Many (M:M)

👉 Many records in Table A = Many in Table B

Example:
Students ↔ Courses

👉 Solution:
Use a junction table

Tables:
students
courses
student_courses (junction)


CREATE TABLE student_courses (
  student_id INT,
  course_id INT
);

Why the Relationship Model.

I. Data Integrity
II. Reduced Redundency
III. Flexibility in Querying

--- 2. SQL Basic ---
🔥 🔹 1. What is SQL?

SQL (Structured Query Language) is used to:
👉 Store, retrieve, and manage data in a database.

🔥 🔹 Main Categories of SQL Commands

SQL commands are divided into 5 main types 👇

✅ 1. DDL (Data Definition Language)

👉 Used to define or modify database structure

Commands:
CREATE → create table/database
ALTER → modify table
DROP → delete table
TRUNCATE → remove all data

Example:
CREATE TABLE employees (
  id INT,
  name VARCHAR(50),
  salary INT
);

✅ 2. DML (Data Manipulation Language)

👉 Used to work with data inside tables

Commands:
INSERT → add data
UPDATE → modify data
DELETE → remove data
Example:
INSERT INTO employees VALUES (1, 'Ram', 50000);

✅ 3. DQL (Data Query Language)

👉 Used to fetch data

Command:
SELECT
Example:
SELECT * FROM employees;

✅ 4. DCL (Data Control Language)

👉 Used to control permissions

Commands:
GRANT → give access
REVOKE → remove access
Example:
GRANT SELECT ON employees TO user1;

✅ 5. TCL (Transaction Control Language)

👉 Used to manage transactions

Commands:
COMMIT → save changes
ROLLBACK → undo changes
SAVEPOINT → temporary save
Example:
ROLLBACK;

--- 4. Basic Database Terminology ---

🔥 🔹 What is Schema?

A schema is the structure (design/blueprint) of a database.

👉 It defines:

Tables
Columns
Data types
Relationships
Constraints
📌 Simple Example
CREATE TABLE employees (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  salary INT
);

🔥 🔹 1. Database Schema

👉 Definition:
A database schema is the overall structure of the entire database.

👉 It includes:

All tables
Relationships between tables
Constraints
Views, indexes
Example:

A company database may have:

employees table
departments table
orders table

👉 All of this together = Database Schema

🔥 🔹 2. Table Schema

👉 Definition:
A table schema defines the structure of a single table.

👉 It includes:

Column names
Data types
Constraints
Example:
CREATE TABLE employees (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  salary INT
);

👉 This is the table schema of employees

🔥 🔹 3. Subschema (View Schema)

👉 Definition:
A subschema is a subset of the database schema that a specific user sees.

👉 It is used for:

Security
Simplicity
Custom views
Example:
CREATE VIEW emp_view AS
SELECT name, salary FROM employees;

👉 User sees only:

name
salary

👉 Not full table → this is subschema

🔥 🔹 What is an Index?

An Index is a data structure that:
👉 Speeds up data retrieval (SELECT queries)

👉 Works like:
📖 Index in a book → helps you find pages quickly

📌 Example

Without index:

Database scans all rows (slow)

With index:

Directly finds data (fast)
🔥 🔹 Syntax
Create Index
CREATE INDEX idx_name
ON employees(name);

🔥 🔹 What is a Query?

A query is a request to the database to get or manipulate data.

👉 In simple words:
Query = asking the database for information

📌 Example
SELECT * FROM employees;

🔥 🔹 What is a Result Set?

A Result Set is:
👉 The output (data returned) after executing a SQL query

📌 Example
SELECT name, salary FROM employees;
Suppose table:
name	salary
Ram	50000
Shyam	60000

🔥 🔹 Simple Meaning

👉 Query = Question
👉 Result Set = Answer

✅ 1. DDL (Data Definition Language)

👉 Used to create and modify structure

Commands:
CREATE → create database/table
ALTER → modify table
DROP → delete table/database
TRUNCATE → delete all data
Example:
CREATE DATABASE company;
CREATE TABLE employees (

✅ 2. DML (Data Manipulation Language)

👉 Used to work with data

Commands:

Example:

✅ 3. DQL (Data Query Language)

👉 Used to fetch data

Command:
SELECT
SELECT * FROM employees;

✅ 4. DCL (Data Control Language)

👉 Used to control access

Commands:
GRANT
REVOKE

✅ 5. TCL (Transaction Control Language)

👉 Used to manage transactions

Commands:
COMMIT
ROLLBACK
SAVEPOINT

This is a very common interview question 👍
Let’s clearly understand DELETE vs TRUNCATE vs DROP 👇

🔥 🔹 1. DELETE

👉 Removes specific rows from a table

Features:
Can use WHERE condition
Deletes row by row
Can rollback (if transaction enabled)
Table structure remains
Example:
DELETE FROM employees
WHERE id = 1;
🔥 🔹 2. TRUNCATE

👉 Removes all rows from a table

Features:
No WHERE condition
Deletes all data quickly
Cannot rollback (generally)
Resets auto-increment
Table structure remains
Example:
TRUNCATE TABLE employees;
🔥 🔹 3. DROP

👉 Deletes entire table

Features:
Removes data + structure
Table is completely deleted
Cannot rollback
Need to recreate table
Example:
DROP TABLE employees;

--- 8. Select Statement ---
🔥 🔹 What is SELECT?

👉 The SELECT statement is used to:
Retrieve (fetch) data from a database table

📌 Basic Syntax
SELECT column_name
FROM table_name;

✅ 1. Select all data
SELECT * FROM employees;

👉 * means all columns

✅ 2. Select specific columns
SELECT name, salary FROM employees;

🔥 🔹 3. WHERE (Filter Data)
SELECT * FROM employees
WHERE salary > 50000;

🔥 🔹 4. ORDER BY (Sorting)
SELECT * FROM employees
ORDER BY salary DESC;

👉 DESC → highest first
👉 ASC → lowest first

🔥 🔹 5. DISTINCT (Unique Values)
SELECT DISTINCT dept FROM employees;

🔥 🔹 6. LIMIT (Top Records)
SELECT * FROM employees
LIMIT 5;

🔥 🔹 7. AND / OR
SELECT * FROM employees
WHERE dept = 'IT' AND salary > 60000;

🔥 🔹 8. LIKE (Pattern Search)
SELECT * FROM employees
WHERE name LIKE 'A%';

🔥 🔹 9. AGGREGATE FUNCTIONS
SELECT AVG(salary) FROM employees;

🔥 🔹 10. GROUP BY
SELECT dept, COUNT(*)
FROM employees
GROUP BY dept;

🔥 🔹 11. HAVING
SELECT dept, COUNT(*)
FROM employees
GROUP BY dept
HAVING COUNT(*) > 5;

--- 9. Where Clause ---

🔥 🔹 What is WHERE Clause?

👉 The WHERE clause is used to:
Filter records based on a condition

👉 It tells the database:
“Give me only the data that matches this condition”

📌 Basic Syntax
SELECT column_name
FROM table_name
WHERE condition;
🔥 🔹 Examples

✅ 1. Simple condition
SELECT * FROM employees
WHERE salary > 50000;

👉 Returns employees with salary > 50,000

✅ 2. Using AND
SELECT * FROM employees
WHERE dept = 'IT' AND salary > 60000;

✅ 3. Using OR
SELECT * FROM employees
WHERE dept = 'IT' OR dept = 'HR';

✅ 4. Using BETWEEN
SELECT * FROM employees
WHERE salary BETWEEN 40000 AND 80000;

✅ 5. Using IN
SELECT * FROM employees
WHERE dept IN ('IT', 'HR');

✅ 6. Using LIKE (Pattern Search)
SELECT * FROM employees
WHERE name LIKE 'A%';

👉 Names starting with A

✅ 7. Using NULL
SELECT * FROM employees
WHERE salary IS NULL;

🔥 🔹 Operators Used in WHERE
Type	Operators
Comparison	=, >, <, >=, <=
Logical	AND, OR, NOT

--- 10. Logical Operator ---

🔥 🔹 What are Logical Operators?

👉 Logical operators are used in the WHERE clause to:
Combine multiple conditions

🔥 🔹 Types of Logical Operators
✅ 1. AND

👉 Returns TRUE if both conditions are true

Example:
SELECT * FROM employees
WHERE dept = 'IT' AND salary > 60000;

👉 Only employees who:

Are in IT
AND have salary > 60,000
✅ 2. OR

👉 Returns TRUE if any one condition is true

Example:
SELECT * FROM employees
WHERE dept = 'IT' OR dept = 'HR';

👉 Employees in IT or HR

✅ 3. NOT

👉 Reverses the condition

Example:
SELECT * FROM employees
WHERE NOT dept = 'IT';

👉 Employees who are not in IT

🔥 🔹 Combined Example
SELECT * FROM employees
WHERE dept = 'IT' AND (salary > 50000 OR age < 30);

👉 Complex filtering using multiple operators

--- 11. Comparison Operator ---

🔥 🔹 What are Comparison Operators?

👉 Comparison operators are used in the WHERE clause to:
Compare values and filter rows

🔥 🔹 Types of Comparison Operators
Operator	Meaning
=	Equal to
!= or <>	Not equal to
>	Greater than
<	Less than
>=	Greater than or equal
<=	Less than or equal
🔥 🔹 Examples

✅ 1. Equal to (=)
SELECT * FROM employees
WHERE dept = 'IT';

✅ 2. Not Equal (!=)
SELECT * FROM employees
WHERE dept != 'HR';

✅ 3. Greater Than (>)
SELECT * FROM employees
WHERE salary > 50000;

✅ 4. Less Than (<)
SELECT * FROM employees
WHERE salary < 30000;

✅ 5. Greater Than or Equal (>=)
SELECT * FROM employees
WHERE salary >= 60000;

✅ 6. Less Than or Equal (<=)
SELECT * FROM employees
WHERE salary <= 40000;

--- 12. Order by Clause ---

🔥 🔹 What is ORDER BY?

👉 The ORDER BY clause is used to:
Sort the result set (output) in ascending or descending order.
ORDER BY sorts ROWS (records).

📌 Basic Syntax
SELECT column_name
FROM table_name
ORDER BY column_name [ASC | DESC];
🔥 🔹 Sorting Types

✅ 1. ASC (Ascending) – Default

👉 Small → Large (A → Z, 1 → 9)

SELECT * FROM employees
ORDER BY salary ASC;

✅ 2. DESC (Descending)

👉 Large → Small (Z → A, 9 → 1)

SELECT * FROM employees
ORDER BY salary DESC;
🔥 🔹 Examples

✅ 1. Sort by one column
SELECT * FROM employees
ORDER BY name;

✅ 2. Sort by multiple columns
SELECT * FROM employees
ORDER BY dept ASC, salary DESC;

👉 First sorts by dept
👉 Then salary within each dept

✅ 3. With WHERE clause
SELECT * FROM employees
WHERE salary > 50000
ORDER BY salary DESC;

--- 13. Limit and Offset, Pagination ---

🔥 🔹 What is LIMIT?

👉 LIMIT is used to:
Restrict the number of rows returned

📌 Syntax:
SELECT * FROM table_name
LIMIT number;

✅ Example:
SELECT * FROM employees
LIMIT 5;

👉 Returns first 5 rows

🔥 🔹 What is OFFSET?

👉 OFFSET is used to:
Skip a number of rows before starting to return data

📌 Syntax:
SELECT * FROM table_name
LIMIT number OFFSET skip_rows;

✅ Example:
SELECT * FROM employees
LIMIT 5 OFFSET 2;

🔥 🔹 What is Pagination?

👉 Pagination means:
Dividing large data into smaller pages

👉 Instead of showing all data at once:

Show 10 records per page

--- 14. MySQL Alias(as)

🔥 🔹 What is Alias?

👉 Alias means:
Giving a temporary name to a column or table

👉 Used to:

Make query short
Improve readability

🔥 🔹 Types of Alias

✅ 1. Column Alias

👉 Rename a column in output

Example:
SELECT name AS employee_name
FROM employees;

👉 Output column name becomes employee_name

✅ 2. Table Alias

👉 Rename table for shorter queries

Example:
SELECT e.name
FROM employees e;

👉 e is alias for employees

🔥 🔹 Alias Without AS

👉 AS is optional

SELECT name employee_name
FROM employees;

🔥 🔹 Example with Calculation
SELECT salary * 12 AS annual_salary
FROM employees;

🔥 🔹 Example with JOIN (Very Important)
SELECT e.name, d.dept_name
FROM employees e
JOIN departments d
ON e.dept_id = d.id;

Remove duplicate values from the result

SELECT DISTINCT column_name

--- 16. Function ---

🔥 🔹 What are SQL Functions?

👉 SQL functions are built-in operations that:
Perform calculations or manipulate data

🔥 🔹 Types of SQL Functions
✅ 1. Aggregate Functions

👉 Work on multiple rows and return one value

Functions:
COUNT()
SUM()
AVG()
MAX()
MIN()
Example:
SELECT AVG(salary) FROM employees;
SELECT COUNT(*) FROM employees;

🔥 🔹 2. What are String Functions?

👉 String functions are used to:
Work with text (characters) in database

🔥 🔹 Common String Functions
✅ 1. UPPER() / LOWER()

👉 Change text case

SELECT UPPER(name) FROM employees;
SELECT LOWER(name) FROM employees;
✅ 2. LENGTH()

👉 Returns number of characters

SELECT LENGTH(name) FROM employees;
✅ 3. CONCAT()

👉 Combine strings

SELECT CONCAT(first_name, ' ', last_name) AS full_name
FROM employees;
✅ 4. SUBSTRING() / SUBSTR()

👉 Extract part of string

SELECT SUBSTRING(name, 1, 3) FROM employees;

👉 First 3 characters

✅ 5. TRIM()

👉 Remove spaces

SELECT TRIM(name) FROM employees;
✅ 6. REPLACE()

👉 Replace text

SELECT REPLACE(name, 'Ram', 'Ravi') FROM employees;
✅ 7. INSTR()

👉 Find position of substring

SELECT INSTR(name, 'a') FROM employees;
✅ 8. LEFT() / RIGHT()

👉 Get characters from left or right

SELECT LEFT(name, 2) FROM employees;
SELECT RIGHT(name, 2) FROM employees;
